# Discord Server 設定教學

這份教學帶你建立一個專供票券 agent 使用的 Discord Server 和頻道，取得 `CHANNEL_ID`，並邀請同組同學加入測試。做完這份，再接著做 [`discord-bot-setup.md`](discord-bot-setup.md)。

## 怎麼讀這份文件

- 操作位置、按鈕名稱一律用**粗體**，中文介面在前，英文介面名稱放在括號裡。
- 每個步驟前面有標記：
  - ✅ 已對照 Discord 官方文件確認
  - ⚠️ 依一般使用經驗寫成，**未能在官方頁面逐字確認**。Discord 常改介面，如果你的畫面跟文字不同，請以實際畫面為準，意思相近的按鈕就是了。
- 本文件寫於 2026-10-25，操作環境是 macOS 上的 Discord 桌面版（網頁版 `discord.com/app` 步驟相同）。

> [!NOTE]
> 查證說明放在文件最後，包含哪些部分查到了官方文件、哪些沒有。

## 事前準備

- 一個 Discord 帳號，已經登入。
- 桌面版 App 或瀏覽器版都可以。下面統稱「Discord」。

## 1. 建立自己的 Discord Server

Server（伺服器）是 Discord 裡一個獨立的聊天空間，由你擔任擁有者。我們另外建一個專用的，不要用平常聊天的那一個，這樣比較安全。

1. 打開 Discord，看**最左邊**那一排圓形圖示（伺服器列）。
2. 拉到最下面，點綠色加號 **＋**（⚠️ 按鈕提示文字：**新增伺服器** / **Add a Server**）。
3. 在彈出的視窗選 **親自創建** / **Create My Own**（⚠️ 另一個選項是用範本，不用選）。
4. 下一個畫面問你這個伺服器是做什麼用的，選 **僅供我和我的朋友使用** / **For me and my friends**（⚠️ 選哪一個都不影響功能）。
5. 在 **伺服器名稱** / **Server Name** 輸入名字，例如 `票券 agent 測試`。圖示可以先不設。
6. 點 **建立** / **Create**（⚠️）。

完成後，你會被帶進新伺服器，左邊伺服器列多了一個新圖示，你是擁有者。

---

## 2. 建立專用的文字頻道

這個 agent 只會讀「一個」頻道（architecture.md 第 13 節說明了原因：能花你 Claude 額度的範圍，就只限在這一個頻道）。所以要建一個專用的，不要拿 `一般` 頻道來用。

1. 在剛建好的伺服器左側，找到 **文字頻道** / **Text Channels** 這個分類標題。
2. 把滑鼠移到分類標題上，點右邊出現的 **＋**（⚠️ 提示文字：**建立頻道** / **Create Channel**）。
   - 也可以在左邊頻道清單的空白處按右鍵，選 **建立頻道** / **Create Channel**。
3. 在 **頻道類型** / **Channel Type** 選 **文字** / **Text**。
4. 在 **頻道名稱** / **Channel Name** 輸入名字，例如 `票券記錄`。
5. 下方有 **私人頻道** / **Private Channel** 開關，**先不要開**。
   - 原因：你的 Server 只邀請信任的同學，用邀請連結控管誰進得來就夠了。私人頻道還要另外替每個人、每個 bot 設權限，初學者很容易設錯。
   - 如果你之後想要更嚴格，再參考 `discord-bot-setup.md` 最後的說明。
6. 點 **建立頻道** / **Create Channel**。

完成後，左邊會看到新的 `# 票券記錄` 頻道，點進去就是這個頻道的畫面。

## 3. 開啟開發者模式

Discord 預設不顯示「ID」這種給程式用的編號。要先打開**開發者模式**（Developer Mode），右鍵選單才會出現「複製 ID」。

**桌面版（macOS）** ✅

1. 點左下角、你頭像旁邊的**齒輪圖示**，打開 **使用者設定** / **User Settings**。
2. 在左邊選單往下找到 **進階** / **Advanced**（在「App 設定」/ App Settings 區塊裡）。
3. 把 **開發者模式** / **Developer Mode** 的開關打開（變成綠色）。
4. 關閉設定視窗（右上角 **✕** 或按 `Esc`）。

**手機版（只有想用手機複製時才需要）** ✅

1. 點右下角你的**頭像**。
2. 點右上角的**齒輪圖示**。
3. 往下捲到 **App 設定** / App Settings 底下的 **進階** / **Advanced**。
4. 打開 **開發者模式** / **Developer Mode**。

> [!NOTE]
> 開發者模式只是多顯示幾個選項，不會改變任何其他東西，也不會讓別人看到你的資料。

## 4. 取得頻道的 CHANNEL_ID

1. 在左邊頻道清單找到 `# 票券記錄`。
2. 在這個頻道上按**右鍵**（Mac 觸控板用雙指點按，或按住 `Control` 再點一下）。
3. 在選單最下面選 **複製頻道 ID** / **Copy Channel ID**（✅ 開了開發者模式後才會出現；手機版是在頻道名稱上長按，⚠️ 選項名稱相同）。
4. ID 現在在你的剪貼簿裡了。它是一串很長的數字，大約 17～20 位，例如 `123456789012345678`（這只是格式範例，不是真的）。
5. 先貼到一個暫時的記事本（例如「備忘錄」）存著，等一下 bot 設定時會用到。

> [!WARNING]
> 右鍵選單裡有很多個「複製 ID」，別複製錯了：
> - **複製頻道 ID**（Copy Channel ID）：在頻道名稱上右鍵 → 這是你要的。
> - **複製伺服器 ID**（Copy Server ID）：在伺服器圖示上右鍵 → 不是這個。
> - **複製使用者 ID**（Copy User ID）：在人的名字上右鍵 → 不是這個。
>
> 貼出來後可以確認一下：你右鍵點的是 `# 票券記錄` 這個頻道，而不是別的東西。

## 5. CHANNEL_ID 是什麼？之後用在哪裡？

**CHANNEL_ID 是什麼**：Discord 給每個頻道的唯一編號。頻道改名字，ID 不會變；但如果你把頻道刪掉再重建，就會是一個全新的 ID，要重新複製。

**它不是機密**：知道這個 ID 的人，沒辦法靠它登入或操控你的 bot。但它對應到你的伺服器，所以也不用刻意公開貼出來。

**之後會在哪裡使用**：

1. 你會把它填進專案根目錄的 `.env` 檔，那一行長這樣（`discord-bot-setup.md` 第 6 步會帶你做）：
   ```
   CHANNEL_ID=你剛剛複製的那串數字
   ```
2. agent 啟動時讀取它，之後只處理這個頻道的訊息。其他頻道、私訊，agent 一律不理（architecture.md 第 4 節與 12.3 節）。
3. 這就是限制「誰能花掉你 Claude 額度」的第一道門（architecture.md 第 13 節）。

## 6. 邀請同組同學加入，方便測試

1. 點畫面左上角的**伺服器名稱**（例如 `票券 agent 測試`），會展開一個選單。
2. 選 **邀請其他人** / **Invite People**（⚠️）。
   - 另一個做法：滑鼠移到頻道 `# 票券記錄` 上，點出現的 **邀請** / **Create Invite** 小圖示（⚠️，人形加號）。
3. 在跳出的視窗裡，先**不要急著複製**。找到下方的 **編輯邀請連結** / **Edit invite link**（⚠️，通常是一行小字或齒輪圖示）。
4. 設定這兩項，降低連結被濫用的風險：
   - **邀請連結過期時間** / **Expire after**：選 **7 天** / **7 days**（或更短）。
   - **使用次數上限** / **Max number of uses**：設成同學人數，或稍微多一點，例如 5。
   - ⚠️ **暫時成員資格** / **Grant temporary membership**：**不要勾**（勾了的話，同學一離線就會被踢出去）。
5. 點 **產生新連結** / **Generate a New Link**（⚠️）。
6. 點 **複製** / **Copy**。
7. 用私訊（LINE、Discord 私訊、學校信箱等）傳給**你要邀請的同學**。

同學點連結後，就會進入你的伺服器。進去之後他們會先看到 `一般` 頻道，請告訴他們要到 `# 票券記錄` 傳票券照片。

**如果要收回邀請**（連結傳錯人，或測試結束了）：

1. 點伺服器名稱 → **伺服器設定** / **Server Settings**（⚠️）。
2. 左邊選單找到 **邀請** / **Invites**（⚠️，在「使用者管理」/ User Management 區塊）。
3. 找到那一條連結，點右邊的 **✕** 刪除。連結立刻失效。

> [!WARNING]
> **邀請連結不要公開分享。**
> - 不要貼到公開的社群、Discord 公開群組、IG 限時動態、GitHub、README 或作業報告裡。
> - 任何拿到連結的人都可以加入你的 Server，並且**直接在頻道裡傳照片**。
> - 每一張照片，agent 都會用掉**你自己的 Claude 額度**（見 architecture.md 第 13 節）。陌生人進來亂傳，你的額度會被消耗，也可能被洗版。
> - 設了「7 天過期」和「使用次數上限」之後，即使連結外流，影響也有限。
> - 如果懷疑外流，立刻照上面的方式刪除連結，再重新產生一條新的。

> [!WARNING]
> **請同學測試時不要傳真實票券的清晰照片。**
> 票券上的票號、QR code、姓名，頻道裡所有人都看得到原圖（bot 不會刪原訊息，見 architecture.md 第 14 節）。測試時請用範例圖、已過期的票、或遮掉票號的圖。
